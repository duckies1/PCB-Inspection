# PCB Inspection

## Problem Statement

We are developing a computer vision system for detecting defects in Printed Circuit Boards (PCBs) using visual inspection.

Existing PCB inspection approaches often rely on relatively large object-detection models, which can make deployment on edge and mobile devices challenging due to constraints on computation, memory, and inference latency.

This project explores **YOLO26 as the base detection architecture**, with the goal of developing a lightweight and efficient PCB defect detection system suitable for **edge and mobile deployment**.

## Goals

- Detect common PCB defects reliably using visual inspection.
- Use YOLO26 as the base detection architecture.
- Optimize the model for resource-constrained edge/mobile devices.
- Maintain a practical balance between **detection accuracy, inference speed, and model size**.
- Evaluate the system using publicly available PCB defect datasets.
